Checks every app daily: known vulnerabilities in its Go packages, risky container settings, and secrets committed to its repository. {{if not .Last.IsZero}}Last scan {{.Last.Format "2006-01-02 15:04"}}.{{else}}The first scan runs a couple of minutes after Berth starts.{{end}} Nothing is changed and no secret value is ever read into this page.

Read the results carefully. A clean result means no known problem, not that something is safe. A package listed here uses a version with a published vulnerability: that is a reason to update, but the flaw may not be reachable from your code. Package versions are compared with the public Go vulnerability database (vuln.go.dev) on this server: only that database's generic index is downloaded, your package list is not sent anywhere.
